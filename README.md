# Loan Analysis - Power BI Dashboard

## 📊 Project Overview
This project presents an interactive **Loan Analysis Dashboard** built with Power BI.  
The dashboard provides insights into loan applications, approvals, rejections, and customer risk factors.  
It is designed to help financial institutions, analysts, and stakeholders understand loan performance and improve decision-making.

## 🗂️ Features
- **Loan Status Analysis** – Approved vs. Rejected loan applications.
- **Customer Demographics** – Insights based on gender, marital status, and dependents.
- **Income & Loan Trends** – Relationship between applicant income, co-applicant income, and loan amount.
- **Credit History Impact** – Loan approval patterns based on applicant credit history.
- **Interactive Filtering** – Drill-down capabilities for branch-wise, region-wise, or demographic-wise analysis.
